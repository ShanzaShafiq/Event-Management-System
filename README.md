
# 🎉 Event Management System

A desktop-based **Event Management System** developed using **Java Swing**, designed to streamline event organization, user management, and attendee registration through an intuitive graphical interface.


## 📌 Overview

This application provides a structured platform where administrators can manage events and users, while attendees can register, explore events, and participate efficiently. The system demonstrates core software engineering principles including modular design, role-based access, and interactive UI handling.


## ⚙️ Key Features

### 🔐 Admin Module

* Secure authentication (limited login attempts)
* Event management (Create, Update, Delete)
* User management
* System reports and statistics

### 👤 Attendee Module

* User registration with custom credentials
* Secure login functionality
* Browse available events
* Register for events (Free & Paid)
* Payment simulation for paid events
* View personal registrations



## 🛠️ Technologies Used

* **Java (Core)**
* **Java Swing (GUI Development)**
* **Object-Oriented Programming (OOP)**
* **ArrayList (In-memory data handling)**

## ▶️ Execution Guide

1. Open the project in any Java IDE (IntelliJ / Eclipse / NetBeans)
2. Run the entry file:
 RoleSelectionGUI.java
3. Select the desired role (Admin / Attendee) to proceed
